# Entrega Final - Glossário
<br>

- API (Application Programming Interface): <br> - Conjunto de rotas e regras que permite que diferentes softwares se comuniquem e troquem dados.
- Bcrypt:  <br> - Algoritmo de hash de senha projetado para ser seguro contra ataques de força bruta.
- Controller:  <br> - Camada da arquitetura MVC responsável por processar as requisições, aplicar regras de negócio e definir as respostas.
- CORS (Cross-Origin Resource Sharing):  <br> - Mecanismo baseado em cabeçalhos HTTP que permite a um servidor indicar quaisquer origens diferentes da sua própria das quais um navegador deve permitir o carregamento de recursos.
- Express.js:  <br> - Framework web leve e minimalista para Node.js focado em roteamento e middlewares.
- JSON:  <br> - Formato de texto leve e independente para intercâmbio de dados.
- JWT (JSON Web Token):  <br> - Padrão de mercado para transferência segura de declarações entre duas partes como um objeto JSON assinado digitalmente.
- Middleware:  <br> - Função com acesso aos objetos de requisição (req), resposta (res) e à próxima função middleware (next) no ciclo de solicitação-resposta da aplicação.
- Mongoose:  <br> - Biblioteca de modelagem de dados de objeto (ODM) para MongoDB e Node.js.
- OpenAPI / Swagger:  <br> - Especificação e conjunto de ferramentas para descrever, produzir, consumir e visualizar serviços web RESTful.
- Payload:  <br> - O corpo de dados úteis enviados em uma requisição ou resposta HTTP.
- REST (Representational State Transfer):  <br> - Estilo arquitetural para sistemas distribuídos focado em recursos, verbos HTTP e comunicação sem retenção de estado (stateless).
- Webhook:  <br> - Método de alteração do comportamento de uma página web ou aplicação web por meio de callbacks acionados por eventos em tempo real.
- Zod:  <br> - Biblioteca de declaração e validação de esquemas TypeScript-first para validação de dados em runtime.
