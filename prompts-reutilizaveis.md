# Entrega Final - Prompts Reutilizáveis
<br>

1. Quiz Interativo com Avaliação de Respostas<br><br> 
"Quero revisar o tópico [TÓPICO] dentro de [ÁREA/MÓDULO]. Por favor, crie [NÚMERO] perguntas de [MÚLTIPLA ESCOLHA / DISSERTATIVAS] de nível [INICIANTE / INTERMEDIÁRIO / AVANÇADO] para testar meus conhecimentos. Não me dê o gabarito agora; aguarde eu enviar minhas respostas para me avaliar e explicar os erros."<br><br> 
•	Exemplo de uso: 
"Quero revisar o tópico [Métodos HTTP e Status Codes] dentro de [APIs RESTful]. Por favor, crie **** perguntas de [MÚLTIPLA ESCOLHA] de nível [Iniciante] para testar meus conhecimentos. Não me dê o gabarito agora; aguarde eu enviar minhas respostas para me avaliar e explicar os erros."
________________________________________
2. Simulação de Code Review (Identificar Más Práticas e Bugs)<br><br> 
"Atue como um Code Reviewer Sênior. Crie um trecho de código em [LINGUAGEM/FRAMEWORK] sobre [TÓPICO] contendo [NÚMERO] erro(s) ou má(s) prática(s) comum(ns). Peça para eu identificar os problemas e propor a correção, sem me dar spoilers das falhas antes da minha resposta."<br><br> 
•	Exemplo de uso: 
"Atue como um Code Reviewer Sênior. Crie um trecho de código em [Node.js/Express] sobre [Tratamento Global de Erros e Status Codes] contendo **** más práticas comuns. Peça para eu identificar os problemas e propor a correção, sem me dar spoilers das falhas antes da minha resposta."
________________________________________
3. Design e Modelagem de Endpoints (Cenário Prático)<br><br> 
"Apresente um cenário real de aplicação sobre [DOMÍNIO DA APLICAÇÃO]. Peça para eu desenhar a estrutura de endpoints REST para a funcionalidade de [FUNCIONALIDADE] (informando verbos HTTP, URLs, parâmetros e status codes de resposta). Avalie minha proposta técnica após o meu envio."<br><br> 
•	Exemplo de uso: 
"Apresente um cenário real de aplicação sobre [E-commerce / Carrinho de Compras]. Peça para eu desenhar a estrutura de endpoints REST para a funcionalidade de [Gerenciamento do Carrinho] (informando verbos HTTP, URLs, parâmetros e status codes de resposta). Avalie minha proposta técnica após o meu envio."
________________________________________
4. Comparativo de Decisão Técnica (Trade-offs)<br><br> 
"Crie um dilema técnico comparando [TECNOLOGIA/ABORDAGEM A] versus [TECNOLOGIA/ABORDAGEM B] no contexto de [DESAFIO DE API]. Faça [NÚMERO] perguntas para que eu escolha a melhor opção para o cenário e me peça para justificar. Analise minha resposta em seguida."<br><br> 
•	Exemplo de uso: 
"Crie um dilema técnico comparando [Polling] versus [Webhooks] no contexto de [Integração com Gateway de Pagamentos PIX]. Faça **** perguntas para que eu escolha a melhor opção para o cenário e me peça para justificar. Analise minha resposta em seguida."
________________________________________
5. Explicação Conceitual com Validação de Precisão<br><br> 
"Vou explicar com minhas próprias palavras como funciona [CONCEITO/MECANISMO] no contexto de APIs. Por favor, analise minha explicação e aponte: 1) O que está correto, 2) O que faltou ou ficou ambíguo, e 3) Se cometi alguma imprecisão técnica."<br><br> 
•	Exemplo de uso: 
"Vou explicar com minhas próprias palavras como funciona [o fluxo de Autenticação com JWT e Middlewares no Express] no contexto de APIs. Por favor, analise minha explicação e aponte: 1) O que está correto, 2) O que faltou ou ficou ambíguo, e 3) Se cometi alguma imprecisão técnica."
________________________________________
6. Mock Interview (Simulação de Entrevista Técnica)<br><br> 
"Simule uma pergunta clássica de entrevista técnica para desenvolvedor Backend sobre [TÓPICO CRUCIAL DE API]. Faça apenas uma pergunta por vez e aguarde minha resposta antes de me dar feedback e passar para a próxima."<br><br> 
•	Exemplo de uso: 
"Simule uma pergunta clássica de entrevista técnica para desenvolvedor Backend sobre [CORS e Política de Mesma Origem (SOP)]. Faça apenas uma pergunta por vez e aguarde minha resposta antes de me dar feedback e passar para a próxima."
